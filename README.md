# ai301-coursework

This is my single repository for AI301 (AI Open Source Capstone). I created
it in Unit 1 from the course template. At every check-in I submit this
repo’s root link — not a path to a folder or file — and graders open the
folder for that unit’s work themselves.

**Submission URL (always the repo root):**
https://github.com/Anush-Prabhu/ai301-coursework

## What lives where

- `tools/`: my installed skill folders, one per unit in Beat 1. Unit 1 is
  `issue-select/`, unit 2 `repro-check/`, unit 3 `plan-check/`, unit 4
  `pr-precheck/`. For each unit I upload the current files from my
  installed copy (`~/.claude/skills/<skill>/`).
- `beat-1-sandbox/`: one folder per unit for units 1–4. Each holds that
  unit’s write-up (links, reflection, and my account of the eval
  iterations) and `eval-run.txt`, one complete eval run written by the
  harness with `--save-run`. Unit 3’s folder also holds my `plan.md`.
- `beat-2-contribution/`: `contribution-story.md` is Assignment 5, the
  graded story of my real contribution, built across units 5–8 and
  submitted once. A second contribution is optional and ungraded: copy
  `extra-round-template.md` to `contribution-story-2.md`.
- `beat-3-portfolio/`: `toolkit-portfolio.md` is Assignment 6, the unit 9
  toolkit portfolio. I fill that skeleton in unit 9; until then it waits.

For units 1–4 I put work in two places: `tools/` for that unit’s skill
folder, and `beat-1-sandbox/unit-N/` for its write-up and eval run. Beats
2 and 3 are one file each. I submit the same repo root link every unit.
